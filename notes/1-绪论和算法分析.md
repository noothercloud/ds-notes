# 数据结构基本概念：

数据：对客观事物的符号表示：学生信息

数据元素：数据的基本单位：一个学生的完整信息

数据项：组成数据元素，具有独立意义的最小单位：学号、姓名、年龄

数据对象：性质相同的数据元素的集合：全校学生的信息集合


混淆点：*数据元素*和*数据项*不是绝对固定的成绩，主要关注当前程序把上面作为整体处理

# 逻辑结构与存储结构：

逻辑结构：关心数据之间是什么关系

存储结构：关心数据在计算机中怎么组织

例：线性表既可以用数组实现，也可以用链表实现；逻辑结构没有改变，改变的是存储结构

集合结构：元素之间没有特定关系：集合

线性结构：一对一的前后关系：线性表，栈，队列

树形结构：一对多的层次关系：树

图状结构：多对多的关系：图

# 抽象数据类型ADT

抽象数据类型的思想：描述数据对象、数据关系以及允许进行的操作，而不依赖具体实现。

假设我们设计了一个栈，我们只关心：能不能把元素放进去？能不能把栈顶元素取出来？等，我们不关心栈底层究竟是数组还是链表

## ADT 栈
数据对象：具有相同类型的数据元素集合

数据关系：元素之间具有线性关系

基本操作：

    InitStack()   初始化栈

    Push(x)       入栈

    Pop()         出栈

    GetTop()      获取栈顶元素

    IsEmpty()     判断是否为空

# 算法及算法的特性

## 算法的五个基本特性：

有穷性：执行步骤必须有限：不能永远运行

确定性：每一步含义明确：相同条件下步骤明确

可行性：每一步都能实际执行：不能要求完成无法完成的操作

输入：可以有0个或者多个输入

输出：至少有一个输出

# 时间复杂度

## 四种常见情况

固定数量的操作：\(O(1)\)

一个循环执行n次：\(O(n）\)

两层循环，各执行n次：\(O(n^2)\)

每次循环将问题规模减半：\(O(\log n)\)

*关注增长趋势，忽略常数和低阶项

# 空间复杂度

空间复杂度关注算法运行过程中额外使用的空间睡输入规模增长的趋势

如
```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += i;
}
```

只使用了固定数量的变量，额外空间为\(O(1)\)

但是如果辅助数组长度随n增长，空间复杂度就是\(O(n)\)
