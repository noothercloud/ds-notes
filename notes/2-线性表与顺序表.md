# 线性表与顺序表

## 线性表的定义：

线性表是具有相同数据类型的n个数据元素组成的*有限序列*

三个关键词：

有限：元素个数可以是0，但是不能是无限

同类型：通常要求所有元素属于相同数据类型。

序列：元素之间存在先后顺序

### 线性表的逻辑结构不要求元素在内存中连续存储。连续存储是顺序表的特点。

# 顺序表的插入

## 移动次数

假设顺序表当前长度为n，在第i个位置插入元素（位置从1开始）。

需要移动的元素数量：

```bash
n-i+1
```

## 移动的方式

```cpp
for (int j = length; j >= pos - 1; j--) {
    a[j] = a[j - 1];
}
```

**为什么插入是往后**:

防止覆盖未移动元素

```cpp
#include<iostream>
using namespace std;

const int MaxSize = 100;

Struct SeqList{
    int data[MaxSize];
    int length;
}

bool insert(SeqList &L,int pos,int x){
    if (pos < 0 || pos > L.length ||
        L.length == MaxSize) {
        return false;
    }
        for(int i = L.length;i > pos;i--){
            L.data[i] = L.data[i-1];
        }
    L.data[pos] = x;
    L.length ++;
    return true;
}

bool remove(SeqList &L,int pos){
    if(pos<0 || pos >= L.length || L.length == MaxSize){
        return false;
    }
    
    for(int i = pos;i < L.length + 1;i++) {
        L.data[i] = L.data[i+1];
    }
    
    L.length --;
    return true;
}
```

## 链表

链表和顺序表按照位置访问的时间复杂度对比：

顺序表可以直接按照下表查找，而链表需要从1开始指针，所以链表按照位置访问的时间复杂度是\[O(n)\]

### 链表的通常定义形式

```cpp
struct Node{
    int data;
    Node* next;
};
```
